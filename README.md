# Sarıbay Studio – Dark Cinematic Indie Game Studio Website

Official website for **Sarıbay Studio**, an independent (indie) co-op game development studio founded by **Selahattin Sarıbay** and **Powered By Sarıbay Yazılım**.

## 🚀 Quick Vercel Deployment Instructions

### Option 1: Deploy via Vercel CLI (Recommended)
```bash
# 1. Install Vercel CLI globally (if not already installed)
npm install -g vercel

# 2. Navigate to project folder and deploy
cd "c:\Users\ssari\Desktop\Sarıbay Studio"
vercel

# 3. Deploy to production
vercel --prod
```

### Option 2: Deploy via GitHub + Vercel Dashboard
1. Push this workspace to your GitHub repository:
   `https://github.com/SARIBAYHOLDING/Saribay-Studio.git`
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Select **Import Repository** -> `SARIBAYHOLDING/Saribay-Studio`.
4. Click **Deploy**. Vercel will automatically detect the static build configuration and deploy in seconds!
